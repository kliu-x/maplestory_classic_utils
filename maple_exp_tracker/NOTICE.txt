The map names in maps.txt and the EXP table are from the fan-made MapleStory Classic database MeowDB
(https://meowdb.com). The program code (all the .py files) was written fresh for this tracker.
MapleStory is a trademark of Nexon; this tool is not made by or affiliated with Nexon.

The window's text is set in Manrope (assets/fonts), copyright The Manrope Project Authors, used under the
SIL Open Font License 1.1 (assets/fonts/OFL.txt). The window's look (dark glass cards with gold accents and
three layouts) follows the style of the same community overlay; all of the drawing code is new.

The "MapleStory Classic" design (cream parchment, orange banner, lime EXP gauge, outlined numbers, the maple
leaf) is original artwork drawn by this program's code, inspired by the look of the game's windows. No game
files or game artwork are used. MapleStory is a trademark of Nexon.

assets/chat_glyphs.npz holds about 50 tiny pixel bitmaps of letters of the game's chat font, taken from a screenshot of the
game's chat supplied by the user, so that the tracker can read chat text. It is used only to recognise text on the user's own
screen. The rest of the characters are learned on the user's PC and stored in their data folder.
